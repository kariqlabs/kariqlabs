## Featured Project

### [Bush Canteen POS](https://github.com/kariqlabs/bushcanteen.ms)

A responsive point-of-sale prototype for a Ghanaian restaurant, built with JavaScript and Express. It includes menu browsing, server-side order pricing and validation, local order storage, and printable receipts.

**Project status:** Local evaluation prototype. It does not yet provide user authentication, role-based access, payment-provider verification, or production-grade database storage.
